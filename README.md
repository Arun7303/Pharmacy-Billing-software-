# 💊 Pharmacy Billing & Inventory Management System

A **professional Pharmacy Billing System** built using **Python (PyQt5 + SQLite)**.  
This project helps manage billing, inventory, customers, sales, and generates invoices in PDF format.  
It also includes **email/WhatsApp notifications, auto-backups, and admin settings**.

---

## 🚀 Features

✅ **User Login System** (Admin / Staff)  
✅ **Billing Module** – Add items via barcode scanner or manual input  
✅ **Invoice Generation** – PDF invoices with pharmacy details  
✅ **Customer Management** – Store customer info (name, phone, email, address)  
✅ **Inventory Management** – Add, edit, delete, import/export medicines  
✅ **Stock Alerts** – Low stock & expired medicine alerts  
✅ **Sales Reports** – Generate daily/monthly sales reports with filtering  
✅ **Notifications** – Email receipts & WhatsApp invoice sending  
✅ **Auto Backup** – Daily auto-backup with 7-day retention policy  
✅ **Settings Page** – Admin can configure notification & backup settings
